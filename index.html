3. Environment and setup

XAMPP Apache + MySQL green; create database kvskill (utf8mb4_unicode_ci, root / blank). Do not run composer create-project (pre-downloaded Laravel, no network). Unzip media files to Desktop for upload tests.

.env — 7 lines (DB + session)
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=kvskill
DB_USERNAME=root
DB_PASSWORD=
SESSION_DRIVER=file

Then php artisan key:generate; create public/uploads; serve with php artisan serve (http://127.0.0.1:8000). Verify PHP 8.2+ and Laravel 12.x via php --version / php artisan --version.

5. System design (C1, C3–C9)

5.1 Layout contract

One layout.blade.php extended by all views; plain <style> only (no Vite/Tailwind); mandatory <meta name="csrf-token"> for AJAX; thumbs object-fit:cover; middle image keeps original ratio.

5.2 Auth (C3)

Login validates required; Hash::check; mismatch returns Username and password not matched. Register validates username required|unique, confirm required|same:password (Password and confirm password must matched.), category_id required|exists; duplicate returns Username already exists. Success → / with Registered. Please login.

AuthController.php (~45 lines)
// loginForm -> view login
// login: validate username+password required; find by username;
//   !user || !Hash::check -> back with 'Username and password not matched.'
//   session user_id/username/role; role 1 -> /users else /reports
// logout: session flush -> /
// registerForm: Category::all -> view register
// register: validate + unique/same/exists with custom messages;
//   User::create username, Hash::make password, role 0, category_id -> / with ok

5.3 One Page (C4) and Slide (C5)

Index: where status 0 + photos count > 0; thumb = first photo; title + owner + 100-char desc; click → /reports/{id}. Slide top: Title/Name/Category (owner's)/Date/Description; middle: first photo default; bottom: thumbs + Prev/Next + Photo X of N + highlight; thumbnail/Prev/Next update via JS array + index, no reload.

5.4 My Reports (C6)

where user_id = session; empty = 150px grey #aaa box; X form POST /my-reports/{id}/delete unlinks files then deletes; + opens modal (Title/Description/Date required, Status 0/1, kategori display-only from profile); Add creates → /manage/{newId}; Cancel resets + closes.

5.5 Manage (C7 top, C8 bottom)

Top: load title/description/kategori(text)/date/status; validate required + in:0,1; Update → /my-reports; Reset restores originals. Bottom: thumbs square; click → fullscreen overlay; X → DELETE /photos/{id}; + → multi file picker auto-upload; drag-drop auto-upload with blue-dash + #e0e7ff highlight; new thumbs appended without reload.

PhotoController.php + GD resize (~70 lines)
// upload($id): owner check; validate photos.* image max 5120;
//   mkdir public/uploads; per file: name uploads/time_uniqid.ext;

5.6 Users (C9, admin only)

Guard session role != 1 → /; list role 0 only; kategori via category_id; rcount = COUNT reports by user; pcount = COUNT photos via report ids; Delete unlinks files then deletes user (cascade clears rows).

Appendix A. Pitfalls and file map

Cascade in migrations + manual unlink. 6. object-fit:cover for thumbs only. 7. Paper typos: Gallery/Albums/Slide = One Page/Reports. 8. Kategori display-only from Category_Id. 9. Date input type=date. 10. Submit to C:\xampp\htdocs\YOUR_IC_Module_C.

Files (~17): 8 views (layout, login, register, onepage, slide, myreports, manage, users) + 4 controllers (Auth, Report, Photo, User) + routes/web.php + 4 migrations + 1 seeder + 4 models + public/uploads.
